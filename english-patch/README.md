# English Patch files

Reserved for the unofficial Honor of Kings: ACE English Patch and future
translation files used by the patcher. No patch release is published here yet.

- `translations/`: reviewed translation data, to be added later.
- Document the supported game-client version and file format with each upload.
- Add patcher update metadata only when its required format is defined.

This folder is public in the repository. It is separate from the `docs/` folder
used by GitHub Pages. Do not place credentials, account data, local logs, or
unrelated game-installation files here.
